# MUKYUL SKIN LAB — 홈페이지 (5페이지)

정적 사이트입니다. 서버 프로그램도 데이터베이스도 필요 없습니다. **폴더째 올리면 끝입니다.**

```
index.html      홈 — 히어로 · 피부 레벨 측정 · 오픈 프로모션
program.html    프로그램 — 5대 시그니처 · 70분 관리 과정 · 전후 가이드
brand.html      브랜드 — 30년 · 원장 경력 · 다섯 가지 약속 · 공간
price.html      요금 — 전체 요금표 · 멤버십 · 회원권 계산기 · 홈케어
reserve.html    예약 — 상담 채널 · 문의서 · FAQ · 오시는 길

favicon.svg / robots.txt / sitemap.xml / site.webmanifest
assets/
  css/style.css       디자인 (5페이지 공용)
  js/config.js   ★    지점 정보 · 가격 — 여기만 고치면 됩니다
  js/main.js          동작 (측정 · 계산기 · 문의 · 메뉴)
  img/                사진과 자리 그림
```

## 1. 올리는 법 — Netlify가 제일 빠릅니다

1. [app.netlify.com/drop](https://app.netlify.com/drop) 접속
2. **이 폴더(또는 `무결_홈페이지_업로드용.zip`)를 화면에 끌어다 놓기**
3. 끝. 1분 안에 `https://랜덤이름.netlify.app` 주소가 나옵니다

**무료이고, 로그인 없이도 누구나 그 주소로 들어올 수 있습니다.** 나중에 계정을 만들면 주소 이름을 바꾸거나 직접 산 도메인을 연결할 수 있습니다.

다른 선택지도 됩니다 — Vercel(무료), GitHub Pages(무료), Cafe24·가비아·닷홈(FTP로 `public_html`에 업로드).

## 2. 올리기 전에 채울 것

### `assets/js/config.js` — 이 파일 하나가 5페이지 전체를 바꿉니다

| 항목 | 지금 값 | 해야 할 일 |
|---|---|---|
| `tel` | `02-0000-0000` | **실제 전화번호** |
| `address` | `주소 확정 후 기재` | **실제 주소** |
| `url` | `https://example.com` | **실제 도메인** |
| `bizInfo` | 기재 예정 | 상호 · 대표자 · 사업자등록번호 |
| `hoursWeek` / `hoursRest` | 임의 기입 | 실제 영업시간 |

### 각 HTML 안의 `https://example.com`

5개 파일 모두의 `canonical`·`og:url`·`og:image`, 그리고 `index.html`의 구조화 데이터에 들어 있습니다. **일괄 바꾸기로 실제 도메인으로 교체**하세요. 여기가 틀리면 **카카오톡 공유 미리보기가 깨집니다.**

`robots.txt`, `sitemap.xml` 도 같이 바꿔 주세요.

## 3. 사진

`assets/img/` 안에 두 종류가 있습니다.

**실제 사진 (그대로 쓰셔도 됩니다)**
- `product.png` — 데일리 리페어 마스크 제품컷
- `levels.png` — 01~05 시트 스와치
- `og.png` — 카카오톡 공유 미리보기 (1200×630)

**자리 그림 (실제 사진으로 바꿔야 합니다)**
- `measure.svg` 측정실 · `room.svg` 관리룸 · `dome.svg` 미니 돔
- `reception.svg` 리셉션 · `director.svg` 원장 · `signature.svg` 서명

사진을 찍으신 뒤 같은 이름으로 바꿔 넣고, HTML의 `src`만 `.svg` → `.jpg` 로 고치면 됩니다. 규격은 `assets/img/README.txt` 에 있습니다.

> **용량 팁** — `product.png`·`levels.png` 는 PNG라 무겁습니다(350~520KB). [squoosh.app](https://squoosh.app) 에서 **WebP나 JPEG로 바꾸면 1/5로 줄어듭니다.** 모바일 속도에 도움이 됩니다.

## 4. 예약 문의를 실제로 받으려면

지금은 **접수 기능이 없습니다.** 내용을 정리해 복사·카카오톡 공유·전화로 넘길 뿐입니다.

`config.js` 를 고치면 실제 접수가 가능합니다.

```js
form: {
  mode:     "none",     // → "post"
  endpoint: ""          // → 접수받을 주소
}
```

- **Formspree** — 문의가 메일로 옵니다. 월 50건 무료
- **Google Apps Script** — 스프레드시트에 쌓입니다. 무료, 무제한
- **네이버 예약 · 카카오톡 채널** — 상담 채널 버튼에 링크만 연결

> **개인정보를 받는 순간부터 개인정보처리방침 페이지가 필요합니다.** 지금은 없습니다. 폼을 여시기 전에 준비하세요.

## 5. 가맹점을 늘릴 때

**`config.js` 한 파일만 바꾸면 새 지점 사이트가 됩니다.** 폴더를 복사하고 아래 세 줄만 고쳐서 올리면 끝입니다.

```js
area:   "분당",
branch: "분당 2호점",
tel:    "031-111-2222",
```

→ 5페이지 전체의 제목, 우측 레일 전화번호, 전화 걸기 링크, 오시는 길, 예약 문의 양식이 **자동으로 바뀝니다.** 실제로 테스트해 확인했습니다.

가격이 지점마다 다르면 `programs` 의 `price` 와 `ten` 을 고치세요. **`ten` 은 `price × 0.85 × 10`** 입니다 — 이 규칙을 깨면 요금표와 회원권 계산기가 어긋납니다.

디자인·문구·기능(`style.css`, `main.js`)은 **모든 지점이 공유**하므로 본사에서 한 번 고치면 됩니다.
